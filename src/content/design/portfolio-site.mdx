## Context

My projects don't sit in one discipline. A macro pad is firmware and a 3D-printed case; a drawing app is a Kotlin codebase and a UI; a poster is design. A single grid of cards treats all of them the same, which hides the thing I most want to show: how I move between them.

<Callout>How might one site show range across disciplines without feeling like three different people made it?</Callout>

## Concept

The site starts as a sketchbook: a hand-drawn version of me waving hello on a plain page. From there it branches. Every discipline page re-renders the same skeleton in its own idiom, so the contrast between pages carries the idea that it's one person working in three modes.

## System

The themes aren't separate stylesheets for separate components. Every page reads the same small contract of variables (surface, ink, accent, display face, radius, motion ease), and each discipline only overrides those values plus a few signature idioms. That keeps the components shared and the pages distinct, and it made dark mode a single extra layer per theme instead of a rewrite.
